# Standard decision-log summary

The detailed [decision and project logs](12-project-logs.md) are the source record.

| Decision | Choice | Why |
| --- | --- | --- |
| Delivery method | Hybrid: predictive baseline plus three Scrum sprints | Scope, budget, risks, and governance need control; iterative work needs feedback. |
| MVP implementation | Airtable + Make | Suitable for an illustrative low-code workflow and portfolio validation. |
| Design | Figma | Allows staff-focused workflow review before build changes. |
| Work management | Jira | Provides epics, stories, workflow, sprint allocation, and traceability. |
| Reminder safety | Test-only, no live provider | Consent, privacy, vendor, reliability, and pilot approval must precede real messages. |
| Public evidence | Fictional and labelled | Protects privacy and avoids false client/deployment claims. |
