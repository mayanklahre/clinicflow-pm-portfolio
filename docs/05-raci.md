# RACI

One person is accountable for each activity. R = responsible, A = accountable, C = consulted, I = informed.

| Task | PM | Sponsor | Product Owner | Dev | QA | Privacy adviser |
|---|---|---|---|---|---|---|
| Charter and business case | R | A | C | I | I | I |
| Requirements (PRD) | R | C | A | C | C | C |
| Backlog prioritisation | R | I | A | R | C | I |
| Build | A | I | C | R | C | I |
| Consent and data-protection design | C | I | C | R | C | A |
| Test plan and UAT | A | I | R | C | R | I |
| Budget and change control | R | A | C | I | I | I |
| Go-live approval | R | A | C | C | C | C |
| Weekly status report | A/R | I | I | C | C | I |
| Risk register upkeep | A/R | I | C | C | C | C |
