# Standard risk summary

The detailed weekly [risk register](06-risk-register.md) is the source record.

| Risk | Mitigation |
| --- | --- |
| Staff resistance | Co-design, training, pilot, and feedback loops. |
| Double booking | Unique-slot rules, re-check before confirmation, tests; production-grade atomic locking remains a future improvement. |
| Scope creep | MoSCoW priorities and change control. |
| Team availability | Sprint buffer and cross-training. |
| Outage | Offline paper fallback and reconciliation process. |
| Data/privacy incident | Minimum data, consent, access control, privacy review, and no public patient records. |
| Messaging provider failure | Vendor comparison, exception queue, fallback channel, and no automation before approval. |
| Budget overrun | Illustrative baseline, contingency, and recurring review. |
